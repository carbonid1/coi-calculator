0.4.1
- Dashboard can now be disabled and is off by default.
- Tightened the layout and aligned total trains with the other stats.
- Disabling it hides the UI and stops dashboard updates.

0.4.0
- Added a live capacity dashboard for non-empty Train Networks.
- Shows occupied trains, busy Waiting bays, and train counts by wagon type.
- Supports Unit, Loose, Fluid, Molten, Universal, Mixed, and generic trains.
- Updates only while open and stores no history.

0.3.9
- Removed the incorrect Trains expansion dependency.
- Fixed COI Hub trying to install the expansion as a mod.

0.3.8
- Fixed the jam delay carrying across separate track waits.

0.3.7
- Added grouped jam alerts for sustained fleet congestion.
- Alerts start at three trains and 10% of the active fleet.
- Clicking the alert cycles through affected trains.
- Added a 1–12 month delay and optional pause.
- Added shared Mod Settings support.
